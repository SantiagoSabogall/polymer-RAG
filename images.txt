- Fase 2: Markdown → LLM openai/gpt-5.6-luna (solo texto)

2. Filtrado de Imágenes (Anti-desperdicio de tokens)
Estrategia recomendada: Clasificador barato en 2 pasos
Paso A: Filtro heurístico (sin costo)
# Reglas para descartar imágenes obviamente irrelevantes
def is_candidate_image(img_path):
    img = Image.open(img_path)
    w, h = img.size
    
    # Descartar: logos, íconos, decorativas
    if w < 100 or h < 100:
        return False
    
    # Descartar: imágenes demasiado pequeñas (thumbnails)
    if w * h < 50000:
        return False
    
    # Descartar: ratio de aspecto extremo (banners, líneas)
    ratio = max(w/h, h/w)
    if ratio > 5:
        return False
    
    return True
Paso B: Clasificador con modelo barato (~$0.15/1M tokens)
# Usar GPT-4o-mini o Gemini Flash para clasificar
def classify_image(client, img_base64):
    response = client.chat.completions.create(
        model="openai/gpt-4o-mini",  # Barato: $0.15/$0.60 per 1M tokens
        messages=[{
            "role": "user",
            "content": [
                {"type": "text", "text": "Does this image contain a table or chart with WVTR, water vapor transmission rate, or permeability data? Answer ONLY: yes or no"},
                {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{img_base64}"}}
            ]
        }],
        max_tokens=10
    )
    return "yes" in response.choices[0].message.content.lower()
Costo estimado del filtrado: ~$0.001 por imagen (1000 imágenes ≈ $1)
